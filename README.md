# Santanu Roy — research website

Static personal research website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a public GitHub repository named `66santanu.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and the `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Visit `https://66santanu.github.io` after GitHub finishes deployment.

## Update the site

- Edit text and links in `index.html`.
- Adjust colors and layout in `styles.css`.
- Keep `assets/research-overview-v2.webp` when uploading; it is the research-overview illustration used by the page. The original `research-overview.webp` remains as a fallback.
- Replace the `SR` monogram block with a professional photo later if desired.

The site has no build step or runtime dependencies. The Google Fonts links gracefully fall back to system fonts if unavailable.
